## ⚡ Quick Setup (1-Click)

### Windows
Double-click `setup.bat` or run:
```powershell
.\setup.ps1
```

### Linux / macOS / Git Bash
```bash
chmod +x setup.sh && ./setup.sh
```

### Start Server
- Double-click `start.bat` or run `php artisan serve`
- Open **http://127.0.0.1:8000** in your browser

For comprehensive documentation, database configuration, and troubleshooting, read the **[SETUP.md](SETUP.md)** guide.

## ✨ Features
- 📊 **Dynamic Dashboard**: Financial overview, live budget progress meter, daily spending average, and health score.
- 🏷️ **Category Management**: Create, edit, and organize custom expense & income categories.
- 💸 **Expense Ledger**: Advanced multi-criteria search (by merchant, note, payment mode, date range, or category).
- 📈 **Visual Analytics**: Interactive 6-month line curves and category doughnut split charts.
- 📑 **Data Exports**: Instant formatted PDF statements & CSV spreadsheet exports.
